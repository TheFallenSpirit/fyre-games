# Contributing to Fyre Games
How to report issues and contribute to Fyre Games.

## Bug Reports
Did you find a bug? Please make an [Issue](https://github.com/TheFallenSpirit/fyre-games/issues).
Make sure to search through existing issues to make sure no one has already reported it.

## Feature Requests
To request a feature, please join [Fyre Hub](https://discord.gg/SNxqD4ujTF) on Discord and visit `#suggestions`.

## Code Contributions
If you want to add a new feature or fix a bug, please open a [Pull Request](https://github.com/TheFallenSpirit/fyre-games/pulls).
Make sure to include a proper description of what your pull request adds/fixes, and why you think it should be merged.
